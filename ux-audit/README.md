# BauPro UX Audits

Dieser Ordner enthält dokumentierte UX-Prüfungen mit Screenshots und priorisierten Handlungsempfehlungen.

## Aktueller Review

- [UX Review vom 2026-07-01](./2026-07-01/UX_REVIEW.md)

## Zweck

Die Reviews dienen als nachvollziehbare Design- und Bedienbarkeitsbasis für BauPro. Sie zeigen konkrete mobile Screens, priorisierte Risiken und empfohlene Korrekturreihenfolgen.

## Umgang mit Screenshots

- Screenshots werden mit Datum versioniert.
- Bilddateien müssen echte PNG-Dateien sein, wenn sie die Endung `.png` tragen.
- Große Full-Page-Screenshots sind erlaubt, sollten aber nur dort gespeichert werden, wo sie als Evidenz für einen UX-Befund gebraucht werden.
